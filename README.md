1. Présentation du projet
Ce projet consiste à créer un modèle d’intelligence artificielle capable de reconnaître différents sons à l’aide de la plateforme Teachable Machine.
Le principe est d’enregistrer plusieurs exemples sonores pour chaque classe, d’entraîner le modèle, puis de le tester en direct avec le microphone de l’ordinateur.
L’objectif est de permettre au modèle de distinguer les sons appris et de prédire la classe correspondant au son qu’il entend.

4. Étapes de réalisation
Étape 1 : Création du projet
J’ai ouvert Teachable Machine et créé un nouveau projet de type « Audio Project ».
Étape 2 : Création des classes
J’ai créé les classes correspondant aux différents sons que je souhaitais faire reconnaître par le modèle.
Étape 3 : Enregistrement des sons
J’ai utilisé le microphone pour enregistrer plusieurs échantillons sonores dans chaque classe. Ces exemples servent de données d’apprentissage pour l’intelligence artificielle.
Étape 4 : Entraînement du modèle
Après avoir enregistré les échantillons, j’ai lancé l’entraînement du modèle. Pendant cette étape, le système apprend à distinguer les caractéristiques des sons associés à chaque classe.
Étape 5 : Test en direct
J’ai utilisé le microphone pour tester le modèle et observer les prédictions obtenues. Le modèle affiche des scores qui indiquent à quelle classe le son détecté semble correspondre.

5. Résultats obtenus
Le projet a pour objectif de permettre au modèle de reconnaître les sons enregistrés pendant la phase d’apprentissage.
